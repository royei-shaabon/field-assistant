# רשימת צילומים לשלב 5

יעד: לפחות 20 תמונות בדיקה של לוח המחוונים, לסף הקבלה של `identify` (18 מתוך 20).
כללים: רק צילום עצמי (לא מהאינטרנט), טלפון רגיל, הקטנוע של `knowledge/device.yaml`.

## בטיחות בצילום
- מדליקים רק נוריות שאפשר להדליק בלי לפרק, בלי לגרום תקלה ובלי לנסוע.
- את רשימת הנוריות שאפשר להדליק בבטחה מאשרים מול המדריך ומול המכונאי. זו שאלה פתוחה באפיון.
  נורית שאי אפשר להדליק בבטחה מסמנים "לדמות" ולא מצלמים.
